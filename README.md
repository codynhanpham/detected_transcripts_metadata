# Parse Transcripts Metadata from CSV File

This script attempts to efficiently parse the transcripts metadata from the `detected_transcripts.csv` file generated by Vizgen MERFISH pipeline.

## Performance

Processing a ~26 GB `CSV` file with ~300 million rows and 10 columns takes around `1m30s` on a 8-core, 16-thread CPU running at 4.3 GHz. Memory usage is mostly stable at around `1.5 GB` during the entire process when running in chunks of `500,000 rows * 16 threads`.

## Usage

The script requires transcripts to be rows, and at least 3 data columns are expected: `global_z`, `cell_id`, `gene`. The column names are case-sensitive.

Call the executable from the terminal, or with the `-h` flag to see the help message.

```bash
./detected_transcripts_metadata -h
```

In short, use the `-i` flag to specify the input file, and the `-o` flag to specify the output file or directory. To customize the performance, use the `-c` flag to specify the number of rows to read at a time, and the `-p` flag to specify the number of threads to use.

The default for `-c` and `-p` should be sufficient for most use cases.

```bash
./detected_transcripts_metadata \
    -i /path/to/detected_transcripts.csv \
    -o /path/to/output.json \
    -c 500000 \
    -p 16
```

## Output

The output of this script is a JSON file with the following structure:

```json
{
    "cell_count": number,
    "total_transcripts": number,
    "transcripts_within_cells": number,

    "layers_transcripts_count": {
        "0": number,
        "1": number,
        // ...
        // "<global_z index>" : number
    },
    "layers_transcripts_within_cells_count": {
        "0": number,
        "1": number,
        // ...
        // "<global_z index>" : number
    },

    "gene_frequency": {
        "<gene name>": number,
        // ...
        // "<gene name>" : number
    },
    "genes_frequency_per_layer": {
        "0": {
            "<gene name>": number,
            // ...
            // "<gene name>" : number
        },
        "1": {
            "<gene name>": number,
            // ...
            // "<gene name>" : number
        },
        // ...
        // "<global_z index>" : {
        //     "<gene name>": number,
        //     // ...
        //     // "<gene name>" : number
        // }
    }
}
```

In addition to saving a JSON file, one can use the special value `-` with the `-o` flag to print the output to the terminal. In conjunction with the `-q` flag to suppress the info and progress messages, this will create in a clean JSON output to the terminal that can be piped to another command or saved to a file.

```bash
./detected_transcripts_metadata \
    -i /path/to/detected_transcripts.csv \
    -o - \
    -c 500000 \
    -p 16 \
    -q > /path/to/output.json
```

For example, you can use this script within a Python program to parse the metadata and use it for further analysis.

```python
import json, subprocess

json_string = subprocess.run(
    [
        "detected_transcripts_metadata", # path to this executable
        "-i",
        "/path/to/detected_transcripts_csv",
        "-o",
        "-",
        "-c",
        "500000",
        "-q",
    ],
    shell=False, capture_output=True
)

data = json.loads(json_string.stdout)
print(data)
```
